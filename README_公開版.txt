道の駅 全国旅マップ（かわいい全国旅デザイン版）

GitHub Pages へそのままアップロードできます。

主な変更
- アプリ名を「道の駅 全国旅マップ」に変更
- ホーム画面アイコンを可愛い道の駅イラストに変更
- アプリ内の配色・カード・検索欄・地図枠・ポップアップ・固定バーを
  クリーム / グリーン / ピンク / ブルーの旅行アプリ風デザインに統一
- 温泉施設機能はありません
- 鉄道駅・宿泊施設のON/OFFは画面最下部
- 道の駅と宿泊施設は表示範囲・ズームに応じて件数を調整
- 全国35,688件の宿泊施設データを同梱

公開方法
1. GitHubの michinoeki-nature-map リポジトリを開く
2. ZIP内のファイルをすべてリポジトリ直下へアップロード
3. 同名ファイルは上書き
4. Commit changes
5. GitHub Pages が main / (root) なら自動反映
6. Safariで公開URLを開いて再読み込み
