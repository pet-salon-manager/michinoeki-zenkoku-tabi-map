全国宿泊施設の表示方式
--------------------
・道の駅/鉄道駅とは別レイヤーで、hotels.json の宿泊施設を一括表示します。
・🏨 宿泊施設をONにすると hotels.json 内の全件を同時に表示します。
・楽天トラベルAPIは、全国マスタを定期更新する用途で使う想定です。
・現在の hotels.json は空です。全国データを取得・整形して差し替える必要があります。

hotels.json 1件の例:
{"name":"ホテル名","address":"住所","lat":35.0,"lon":139.0,"hotelInformationUrl":"https://..."}
