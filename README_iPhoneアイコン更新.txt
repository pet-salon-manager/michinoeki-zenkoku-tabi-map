道の駅 全国旅マップ：iPhoneホーム画面アイコン更新版

この版では古い「森旅マップ」のPWAキャッシュを避けるため、
manifestとアイコンのファイル名を新しくしています。

GitHubへアップロード後:
1. 既存の「森旅マップ」をホーム画面から削除
2. Safariで公開URLを開く
3. 一度再読み込み
4. 共有 → ホーム画面に追加
5. 表示名「道の駅 全国旅マップ」と新しい道の駅アイコンを確認
6. 追加

新しい主なファイル:
- manifest-v2.webmanifest
- icon-roadstation-192-v2.png
- icon-roadstation-512-v2.png
